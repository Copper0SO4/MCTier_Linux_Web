# Linux Web EasyTier 高级设置

最近维护：2026-10-06。对照当前源码基线 3.10.0 的 Windows 全局高级设置/大厅高级设置、Rust EasyTierAdvancedConfig、network_service 参数映射和随包 EasyTier 2.5.0 `--help`。不改变 Windows/Android 源码。

## 入口与生效时机

创建或加入页面 → 高级选项：节点与信令服务 → EasyTier 高级设置。也可从首页高级网络功能卡、房间网络面板打开。保存后下次手动加入生效；当前 EasyTier 的静默重连保留当前会话配置，不应用未使用的新设置。不会自动加入大厅、触发防火墙授权或修改系统转发。

| 原版设置类别 | Linux Web 状态 |
| --- | --- |
| IPv4 / DHCP | 复用原版固定网段身份选址；可指定10.126.126.1–254，不启用核心DHCP |
| 性能 | 多线程/线程数、延迟优先、smoltcp、MTU、压缩 |
| 代理/出口 | 私有子网共享、系统子网转发、作为出口节点、使用出口节点；端口转发绑定127.0.0.1 |
| KCP / QUIC | 出站代理与禁用输入独立开关，QUIC固定UDP端口 |
| P2P | 自动/仅P2P/仅中继、UDP/TCP/对称NAT打洞 |
| 中继 | 网络白名单、转发RPC、禁用中继KCP、外部网络KCP、限速、私有模式 |
| 路由 | IPv4手动CIDR路由；会覆盖核心学习的部分路由，使用前了解目标网段 |
| 设备 / IPv6 | TUN名称（Linux15字符限制）、虚拟IPv6地址/前缀、禁用IPv6 |
| 监听 | 单端口自动/指定监听；公网映射监听器；默认连接协议 |
| 端口白名单 | TCP/UDP单端口或范围；并非主机防火墙规则 |
| STUN | IPv4/IPv6主机:端口列表；不是WebRTC ICE配置 |
| 加密 | 沿用当前原版参数映射固定AES-256-GCM，不提供失效的禁用加密/算法输入 |
| 无TUN / SOCKS5 | 不开放：无TUN不兼容本应用虚拟IP聊天服务；SOCKS5核心只提供端口参数，尚未接入受限监听 |
| 任意监听器 / 无监听模式 | 不开放：现有端口预留与UFW/firewalld生命周期管理未覆盖这些模式 |
| DNS | 已按用户明确决定全面移除Linux Web功能，不恢复Magic DNS或TLD设置 |
| 全局/大厅配置来源 | 浏览器本地一套保存配置，入房固定快照；未实现原版多大厅配置继承 |

## 使用注意

- 高级设置列表每项独立校验，最多16项，禁止控制字符、命令参数注入。映射监听器只声明已经配置的公网地址，不修改路由器。
- STUN使用`主机:端口`，IPv6使用`[地址]:端口`；留空时不传覆盖参数，沿用核心默认。虚拟IPv6不会替代MCTier当前的IPv4聊天室地址。
- 虚拟网络TCP白名单需要保留14539、14540，否则聊天/文件可能被阻断；这是用户配置的访问限制，不自动扩宽白名单。
- “系统子网转发”“作为出口节点”不会设置sysctl、NAT或防火墙，所需系统配置由用户自行完成。本地Web管理服务仍只监听127.0.0.1:14700，RPC也只监听回环。
- 所有参数经Linux Web的NetworkSettings转换后复用原版apply_advanced_config；默认协议只传一次，未填写时按显式EasyTier节点协议选择。MCTier信令服务地址独立保存。
