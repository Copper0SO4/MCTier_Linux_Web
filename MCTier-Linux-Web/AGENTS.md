# Linux Web 维护规则

开始维护前阅读 `HANDOFF.md` 和 `README.md`，并核对当前源码、分支与工作区。

**每次维护都必须同步更新文档。** 功能、协议、权限、构建方法、已知问题或验收状态变化时，在同一批变更中更新 `HANDOFF.md`；涉及用户可见行为或编译方式时，同时更新本目录及仓库根目录的 `README.md`。记录本次改动依据、与原版差异、实际验证结果及尚未验证部分。历史审计日志不可替代当前接手说明。

Linux 适配应保持在本目录，复用原版协议且保护 Windows/Android。保留用户更改；不得清空或覆盖工作目录。真实房间联机、真实目录操作或系统授权窗口前，明确说明操作并等待用户确认。功能封锁牌与验收结论必须与实现一致。
